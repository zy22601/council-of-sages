# 智者议会 · Council of Sages

> 释迦牟尼、老子、孔子、霍金、巴菲特、爱因斯坦、马斯克、孙子……
> 同一问题，20位智者轮番作答，然后互相辩论。

把你的问题提交给古今中外最智慧的头脑——释迦牟尼用四圣谛拆解，庄子用齐物论消融，马克思用历史唯物论剖析，爱因斯坦用相对性审视……每人用自己的思想体系作答，再互相辩论，最终提炼共识与分歧。

## 这是什么

这不是知识问答。这是**跨文明的思维实验**，专为 Hermes Agent 设计的 Skill。

20位智者，跨越三千年、七大文明领域：东方哲学、战略军事、科学理性、经济资本、创新未来。

## 安装

```bash
mkdir -p ~/.hermes/skills/council-of-sages
cp SKILL.md ~/.hermes/skills/council-of-sages/SKILL.md
```

安装后 `/reset` 或开新会话生效。

## 使用方式

```
/sages
/智者会
问问智者们
他们怎么看
```

然后输入任何问题——从「活着有什么意义」到「AI会有意识吗」到「为什么越长大朋友越少」。
