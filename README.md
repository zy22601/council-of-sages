# 智者议会 · Council of Sages

> 释迦牟尼、老子、孔子、苏格拉底、伊本·赫勒敦、霍金、巴菲特、爱因斯坦、马斯克、孙子……
> 同一问题，21位智者轮番作答，然后互相辩论。

把你的问题提交给古今中外最智慧的头脑——释迦牟尼用四圣谛拆解，庄子用齐物论消融，马克思用历史唯物论剖析，爱因斯坦用相对性审视……每人用自己的思想体系作答，再捉对辩论、元辩论，最终提炼共识、分歧和沉默区。

## 这是什么

21位智者，跨越三千年、五大文明传统。**v2 更新**：

- 🧬 智者风格DNA — 确保每人声音不可混淆
- 🔬 议题研究步骤 — 涉及当代事务时先搜索事实
- 🗡️ 两轮辩论 — 捉对互质 + 全体元辩论（追问最大沉默）
- 🤫 沉默区 — 所有人都回避的维度
- 📋 高频问题匹配表 — 6种问题类型的推荐智者组合
- ⏱️ 7日回响 — 用一个极小的行动实验把智者的话落地

## 安装

```bash
mkdir -p ~/.hermes/skills/council-of-sages
cp SKILL.md ~/.hermes/skills/council-of-sages/SKILL.md
```

## 使用方式

```
/sages
/智者会
问问智者们
```

然后输入任何问题。
